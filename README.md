# EventingBaba — Live Music & Artists Booking Platform

An ultra-high fidelity, motion-rich web experience for **EventingBaba**, built with a Framer-inspired design system, fluid Lenis smooth scrolling, bidirectional entrance animations, interactive horizontal parallax flows, and a 3D perspective card stack for occasions.

## ✨ Key Features

- **60fps/120fps Lenis Smooth Scrolling**: Interpolated motion loop with hardware-accelerated transforms.
- **Custom Adaptive Cursor**: Precision-centered cursor dot and follower with dynamic hover states (`VIEW` badge, magnetic button expansion, and input focus).
- **Celebrations 3D Horizontal Card Stack**: Interactive 3D deck (`perspective: 1400px; transform-style: preserve-3d`) featuring direct category pill navigation, deck counter HUD, and fluid peel-off animation.
- **Horizontal Parallax Showcase**: Multi-card event formats glide synchronized with vertical scroll position.
- **Bidirectional Scroll Reveals**: Framer-style staggered word animations and scroll-linked element appearances.
- **Interactive Modals & FAQs**: Dynamic artist inquiry booking modal, interactive category filter tabs, and animated accordion FAQs.
- **Fully Responsive**: Tailored layouts for desktop, tablet, and mobile with touch-friendly fallbacks.

## 🚀 Tech Stack

- **HTML5 / CSS3 / Vanilla JavaScript** (Self-sufficient, zero-bundle overhead)
- **Lenis** (Smooth scroll engine)
- **Vercel** (Edge static deployment)

## 📦 Deployment

Deploy directly to Vercel:

```bash
vercel --prod
```
